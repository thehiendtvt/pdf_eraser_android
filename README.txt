CÁCH LẤY FILE APK (làm 1 lần, ~5 phút, miễn phí)
1. Tạo tài khoản github.com -> New repository (đặt Private cũng được).
2. Upload toàn bộ nội dung thư mục này (kể cả thư mục .github) lên repo.
   Lưu ý: thư mục ẩn .github phải được upload đủ (kéo thả cả thư mục lên GitHub).
3. Vào tab Actions -> "Build APK" -> chờ ~4-6 phút chạy xong (dấu tick xanh).
4. Bấm vào lần chạy -> mục Artifacts -> tải "pdf-eraser-apk" (file zip) -> giải nén ra app-debug.apk.
5. Chép sang Xiaomi 17 Ultra, mở file, cho phép "Cài đặt từ nguồn không xác định" khi máy hỏi.

DÙNG THỬ NGAY KHÔNG CẦN APK: mở www/index.html bằng Chrome trên điện thoại (cần mạng).
